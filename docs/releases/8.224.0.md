## Changements

- **Refonte graphique : 9 modèles d'interface.** Forge devient le modèle par défaut ; Command Deck, Bento, Console, Orbital, Colonnes, Verre & dock et Mission sont proposés, et **Classique** garde l'interface d'avant à l'identique. Choix dans Paramètres › Interface, dans l'Éditeur de thème ou d'un clic dans la barre d'état. Toutes les pages, boutons et sous-onglets fonctionnent comme avant ; changer de modèle n'interrompt pas une opération en cours.
- **Mode Mission** (menu Système › Missions) : enchaîner les outils d'une intervention — Remise en état PC, PC lent, Préparation PC neuf, Après un écran bleu, Problème réseau, Sauvegarde & migration, ou vos propres missions. Barre de suivi sur chaque page, « Étape terminée » ouvre l'outil suivant, notes par étape, rapport à copier ou exporter, historique.
- **12 nouveaux thèmes clairs** (74 thèmes au total) ; tous les thèmes sombres sont conservés. Filtre Tous / Sombres / Clairs dans Paramètres.
- **Tableau de bord** propre à chaque modèle et **écran de démarrage** aux couleurs du thème.
- **Raccourcis clavier** : Ctrl+1…0 (sections), Ctrl+Maj+M (modèle suivant), Alt+←/→ (page précédente / suivante), flèches dans tous les menus. Aide : touche `?`.
- **Corrections** : barres de progression affichées en rouge à tort (score santé à 100, batterie pleine, fin de scan, de récupération, de sauvegarde et d'image disque).

## Quel fichier prendre

- `Nitrite_8.224.0_portable_complet.exe` : application + logiciels + pilotes + scripts, sans installation.
- `Nitrite_8.224.0_installateur_complet.exe` : même contenu, installé dans Program Files.

Les versions déjà installées se mettent à jour d'elles-mêmes.

## Signature

Tous les binaires de cette release sont signés (Authenticode SHA-256, horodatés
RFC 3161) par `CN=Heiphaistos`, y compris l'exécutable **contenu dans**
l'installeur et dans les bundles complets.

Le certificat est auto-signé : lancer **une seule fois par PC**
`installer-certificat-heiphaistos.bat` (joint) pour que Windows affiche
Heiphaistos comme éditeur au lieu de « éditeur inconnu ».
